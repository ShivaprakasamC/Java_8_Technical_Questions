# Java_8_Technical_Questions
This repository handles the Java 8 important features along with code snippets

Core important features which are enhanced in java 8 are 
- Lamda Expressions
- Method References
- Functional Interfaces
- Optional Class
- forEach method
- Data/Time API
- Static Methods in Interfaces
- IO Enhancements
- Type and Repeating Annotations
- Stream API
- Default Methods
- Base64 Encode Decode
- Collectors Class
